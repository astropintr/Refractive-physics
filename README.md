## 📘 Overview

Refractive physics is a nonlinear‑field approach where interference patterns generate an **effective refractive geometry**.  
This framework naturally produces:

- dark‑matter–like solitons and flat rotation curves,  
- Airy‑like oscillatory modes in galaxies,  
- cosmic acceleration without Λ,  
- refractive black holes,  
- particle‑like localized modes.

The project contains manuscripts, data, scripts, and derivations for the series:

- **Refractive Cosmology I (RC‑I)**  
- **Refractive Cosmology II (RC‑II)**  
- **Refractive Cosmology III (RC‑III)**
